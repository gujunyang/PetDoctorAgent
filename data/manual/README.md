# 人工补充资料（data/manual/）

开源数据集（`data/raw/`）以英文为主，且缺少本地化/商业信息。为提升问诊与推荐的准确性，
请将补充资料以 `.txt` / `.md` 文件放入本目录；`scripts/build_rag.py` 会自动把
`data/manual/` 一并入库（与 `data/raw/` 合并检索）。

> 提示：项目已使用多语言 embedding 模型 `Xenova/paraphrase-multilingual-MiniLM-L12-v2`
> （384 维、50+ 语言），中英文资料均可检索。
> 如需更换模型（例如精度更高的 `Xenova/paraphrase-multilingual-mpnet-base-v2`），
> 设置环境变量后务必重建：`RAGMILL_EMBEDDING_MODEL=... python scripts/build_rag.py --rebuild`

## 建议补充的内容

### 1. 药品说明书（处方药 / 非处方药）
- 药品通用名与商品名、有效成分、适应症、用法用量、禁忌与不良反应
- 适用物种与年龄限制（猫 / 犬 / 幼年 / 老年）、体重剂量换算
- 常见宠物药示例：体内外驱虫药、体外杀螨/抗真菌药（如治猫藓）、抗生素、止吐止泻药、
  皮肤外用药、关节保健品（软骨素/氨糖）、益生菌等
- **重要**：明确标注「处方药需执业兽医诊断后使用」，避免 Agent 越权推荐

### 2. 本地宠物店服务项目
- 门店地址、营业时间、联系电话
- 服务清单与价格：疫苗、驱虫、洗浴美容、寄养、体检、绝育、B 超/X 光等
- 可售商品目录（品牌、规格、价格、库存）
- 急诊/转诊流程与最近的合作宠物医院信息

### 3. 物种与品种特异性知识
- 猫 vs 犬的用药差异（例如对乙酰氨基酚、拟除虫菊酯对猫的毒性）
- 品种易感病（如折耳猫软骨病、金毛/拉布拉多髋关节问题、斗牛犬呼吸综合征）
- 幼年/老年/孕期/哺乳期的护理与用药禁忌

### 4. 紧急情况处置规范
- 中毒（误食老鼠药、巧克力、百合、洋葱等）、大量出血、呼吸困难、
  抽搐、意识丧失、中暑、难产等场景的现场急救与转诊标准
- 与 `safe_check_agent` 中的紧急关键词保持一致，便于安全审查

### 5. 中文症状-疾病对照
- 常见中文主诉（抓痒、呕吐、拉稀、打喷嚏、流泪、跛行等）与可能病因的对照表
- 便于中文用户提问时命中知识库

## 文件格式建议

```
# 标题：XXX 药品说明书
来源：XXX
适用物种：猫/犬
...
正文内容（段落之间空一行，便于语义切分）
```

保持段落清晰、避免超大无换行长文本，可获得更好的 chunk 质量。
