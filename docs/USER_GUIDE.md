# 宠医通 · 使用手册

> 一位助手，看护所有毛孩子。

> 面向使用者（宠物主人）。本助手可帮你**描述宠物症状、获得初步判断与护理建议、推荐用药/保健品、查询宠物病历**。
> ⚠️ 它不能替代执业兽医；情况紧急请立即就医。门店预约与库存查询暂未开放。

---

## 1. 它能帮你做什么

| 功能 | 说明 | 你可以这样说 |
|------|------|-------------|
| 🩺 症状问诊 | 逐步了解症状，给出初步判断、可能的疾病与护理建议 | “我家猫一直呕吐，没精神” |
| 💊 用药/产品推荐 | 推荐药品、保健品、食品，提示处方药（不提供库存查询） | “有什么药可以治猫藓？” |
| 📵 门店预约 / 库存查询 | **暂未开放**，助手会明确告知暂不支持 | （暂不支持） |
| 📋 病历查询 | 汇总宠物档案、既往问诊记录、门诊病历 | “查看旺财的病历” |
| 🚨 安全提醒 | 识别紧急情况，提示尽快就医 | “我家狗误食了老鼠药” |
| 🧠 长期记忆 | 记住你的宠物档案与历史问诊，跨会话可用 | （自动完成） |

助手会自动结合**知识库**（宠物医疗资料）和你的**宠物档案**来回答，检索到的外文资料会自动翻译成中文。

## 2. 开始使用

### 启动

在项目目录运行（Windows 示例）：

```powershell
.\.venv\Scripts\python.exe main.py --user 你的名字
```

看到下面提示即进入对话：
```
=== 宠医通 · 宠物问诊多 Agent 系统（user=你的名字, session=xxxx）===
输入 q 退出
```

### 会话操作

- 直接输入问题并回车即可。
- 输入 `q`（或 `quit` / `exit`）退出。
- `--user 名字`：区分不同用户（各自的宠物和记录互相隔离）。
- `--session 会话号`：**继续之前的会话**（复用上下文）；不加则每次启动是新会话。

> 同一个会话内会记住上下文；换一次运行想接着聊，用 `--session <上次的编号>`。

## 3. 第一步：先告诉它“这是哪只宠物”

每段会话开始，助手会先确认对象宠物，然后核对档案：
- 如果这只宠物**已有档案** → 直接载入它的基本信息与**以往问诊记录**，结合历史帮你判断。
- 如果是**新宠物** → 引导你补充信息（至少**名字**与**猫/犬**，品种/年龄/体重/过敏史选填）后**自动建档**。
- 会话内确认一次后会记住，后续不再追问。

**示例对话：**

```
你：我家狗狗一直抓痒脱毛
助手：请问这次是哪只宠物？告诉我它的名字（或编号）即可。

你：它叫旺财，3岁金毛，犬，对鸡肉过敏
助手：（已为「旺财」建档）根据描述，可能的方向有：跳蚤过敏性皮炎、食物/环境过敏……
      注意：旺财过敏史含鸡肉，请避免含鸡肉的主粮与零食……
```

> 小技巧：如果你在第一句里就带上名字和基本信息（如“旺财，金毛，犬，抓痒”），可以直接建档、少一轮问答。

## 4. 功能与示例

### 4.1 症状问诊 🩺

尽量描述清楚：**症状、持续时间、部位、伴随表现、饮食排泄、精神和用药史**。信息越全，判断越准。

```
你：我家猫这两天频繁呕吐，吐的是没消化的猫粮，精神还可以
助手：可能方向……建议……为进一步判断请补充：呕吐频率？是否腹泻/便血？疫苗驱虫情况？
```

助手会结合知识库给出**可能的疾病、置信度、护理建议**，并在结尾提示需要补充的信息。

### 4.2 用药 / 产品推荐 💊

问药品、保健品、粮食时，助手会推荐并说明**适用物种、年龄、用法用量、注意事项**。库存查询已下线，助手不会提供库存/是否有货信息。

```
你：福来恩滴剂适合多大的狗用？
助手：福来恩滴剂（Frontline）——适用于犬……按体重选择规格；
      严禁用于猫；使用后 48 小时内避免洗澡……
```

> 若涉及**处方药**，助手会提示“请咨询兽医后使用”。跨物种用药有风险，请务必核对适用物种。

### 4.3 查询宠物病历 📋

```
你：查看旺财的病历
助手：【旺财 的病历】
      一、基本档案：名字/编号/物种品种/年龄体重/过敏史/既往病史
      二、既往问诊记录：2025-06-01 皮肤过敏（跳蚤过敏性皮炎）……
      三、门诊病历（如系统已接入）
```

若知道宠物编号，也可直接查：`查看 PET-001 的病历`。

### 4.4 安全提醒 🚨

出现**中毒、误食、大量出血、呼吸困难、抽搐、意识丧失、昏迷、瘫痪、持续呕吐、便血、药物过量**，
或**幼年/老年宠物出现严重症状**时，助手会**立即**提示就医，不再进行常规问答。

```
你：我家狗误食了老鼠药
助手：⚠️ 紧急情况！请立即带宠物去最近的宠物医院。（命中关键词：误食）
```

**安全标记含义：**

| 标记 | 含义 | 建议 |
|------|------|------|
| `safe` | 常规情况 | 按建议观察/护理 |
| `warning` | 有一定风险 | 尽快咨询或就诊 |
| `emergency` | 危及生命 | **立即就医** |

### 4.5 它记得你的宠物 🧠

- **档案**：品种、年龄、体重、过敏史、既往病史，跨会话保存。
- **历史**：每次问诊的结论会归入该宠物的记录，下次问诊时会作为参考（例如自动避开已知过敏原）。
- 换宠物：新开一个会话，在开始时说明是哪只（同一会话内不支持中途切换）。

## 5. 使用技巧

- **描述具体**：年龄、体重、症状时长、频率、部位、伴随症状、饮食排泄、用药史。
- **先说清宠物**：名字 + 猫/犬 (+ 品种/年龄)，便于匹配历史。
- **一次问一件事**：先问诊、再问药，条理更清晰。
- **复述确认**：对结果有疑问时，可追问“为什么？”“还有别的可能吗？”。
- **善用历史**：“它以前也这样吗？”“上次开的药这次还能用吗？”。

---

## 6. 隐私与数据

- 不同 `--user` 的数据相互隔离；同一用户下不同宠物也各自隔离。
- 若后台未启用数据库，记录只在本次运行内有效（退出即清空）。
- 请勿在对话中提交与宠物问诊无关的敏感个人信息。

## 7. 常见问题（FAQ）

**Q：为什么它先问我“哪只宠物”？**
A：为了核对档案、结合既往病史判断。确认一次后本会话不再问。

**Q：为什么我描述症状，它不直接给我开药？**
A：问诊与用药推荐是分开的职责：问诊只做症状分析与护理建议，避免越权开药。想看用药，直接问“有什么药……”。

**Q：为什么病历是空的？**
A：可能是后台的 MCP 病历服务未启动，或该宠物还没有历史记录。请先完成一次问诊。

**Q：可以预约门店服务或查询库存吗？**
A：门店预约与库存查询功能暂未开放，助手会明确告知“暂不支持”。

**Q：能查别人的宠物吗？**
A：不能。数据按用户隔离，只能访问本用户下的宠物。
