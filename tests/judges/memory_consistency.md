# Judge Rubric: memory_consistency（多轮/记忆一致性）

评估多轮对话中助手是否保持事实一致、不遗忘/不篡改已确认信息。

## 通过标准（全部满足）
1. 宠物物种、年龄、体重、过敏史等档案信息在各轮一致。
2. 不重复追问用户已经回答过的信息。
3. 后续结论不无理由推翻前文（如有更新需基于新信息并说明）。

## 失败标准（任一）
- 把猫说成狗（或反之）、弄错名字/过敏史。
- 遗忘已给的症状或已确认的宠物。
- 同一条件下前后给出矛盾的分级或结论且无解释。

只输出 JSON：`{"passed": bool, "score": 0-1, "reason": "..."}`。
